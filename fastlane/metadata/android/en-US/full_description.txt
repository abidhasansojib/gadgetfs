<p>GadgetFS is a USB gadget management utility for provisioning and controlling USB device roles via ConfigFS. It is designed for technical users who need deterministic gadget lifecycle control, descriptor configuration, and reliable enable/disable of gadget functions for validation, debugging, or security-focused setups.</p>

<p>When enabled, connected USB hosts identify the device strictly under the configured role(s), based on the descriptors and functions provisioned through ConfigFS.</p>

<h3>Integrated gadget functions</h3>

<ul>
  <li><b>HID Keyboard / HID Mouse</b> (e.g., /dev/hidg0, /dev/hidg1)</li>
  <li>Additional functions may be supported depending on kernel configuration and device nodes exposed by the system.</li>
</ul>

<h3>Capabilities</h3>

<ul>
  <li>Provision and activate USB gadget functions using <b>ConfigFS</b></li>
  <li>Configure identifiers and descriptors (e.g., VID/PID, strings) where supported</li>
  <li>Bind/unbind UDC reliably with clean teardown paths</li>
  <li>Enable/disable gadget roles with explicit lifecycle states and status visibility</li>
</ul>

<h3>Requirements</h3>

<ul>
  <li><b>Root permissions are required</b></li>
  <li>A kernel with <b>USB gadget + ConfigFS</b> support is required (ConfigFS mounted and accessible)</li>
  <li>Available gadget endpoints depend on kernel configuration (device nodes such as <code>/dev/hidg*</code> must exist)</li>
</ul>
